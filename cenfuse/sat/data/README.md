# Satellite-engine data

rfam_rrna.cm — Rfam covariance models used to tag rDNA-derived satellite families (never centromeric) and,
through the profile HMM inside the 5S model, to find 5S rDNA arrays (cenfuse/rdna.py):
RF00001 5S_rRNA, RF00002 5_8S_rRNA, RF01960 SSU_rRNA_eukarya, RF02543 LSU_rRNA_eukarya.
Downloaded 2026-09-25 from https://rfam.org/family/<ACC>/cm (the release current then: its models were built in July
2024 with Infernal 1.1.4), concatenated in that order; md5 a2816e43b84981918bf79dfb3e748d7d.
